# inspiration

A source of inspiration for game design. Each category has two files:

- `<category>_full.md`: one entry per line, `- Name: description`, grouped under `##`/`###` headings.
- `<category>_index.md`: `Name | line number` pointing at that entry's line in the full file. Regenerate the index after any insertion.

Categories: ability, audio_visual_style, character, crafting_building, difficulty_balance, economy, enemy_ai_behavior, faction, game_mode, item, mechanic, monetization_live_ops, narrative_lore, onboarding_tutorial, point_of_interest, progression, puzzle_minigame, quest, resource, social_multiplayer, status_effect, structure, terrain-biome, ui_feedback, vehicle, world_event.
